# YouTube Keep — полная инструкция: Mac, телефон, вход по ссылке, синхронизация

Цель: одна **ссылка**, которую открываешь на Mac и на телефоне, единый **вход** (GitHub token), и все ссылки / направления / теги **синхронизируются** между устройствами.

---

## Как это устроено

| Часть | Где живёт | Зачем |
|--------|-----------|--------|
| **Приложение** (страница) | GitHub Pages — доступна по HTTPS-ссылке | Открывается на любом устройстве как сайт / PWA |
| **Данные** (ссылки, категории, теги) | Секретный **GitHub Gist** | Облако для синка между Mac и телефоном |
| **«Вход»** | **Personal Access Token** GitHub с правом `gist` | Одинаковый токен на всех устройствах = один и тот же сейф |
| **Локальная копия** | Браузер устройства (localStorage) | Работает офлайн, потом досинхронизируется |

```
  Mac (Chrome/Safari)          GitHub Gist           Android (Chrome)
  ┌─────────────────┐      (секретный JSON)      ┌─────────────────┐
  │  YouTube Keep   │ ◄──── push / pull ────►    │  YouTube Keep   │
  │  + токен/ID     │                            │  + тот же токен │
  └─────────────────┘                            └─────────────────┘
```

## Шаг 1. Выложить приложение в интернет (чтобы была общая ссылка)

Самый простый способ — **GitHub Pages**.

### 1.1 Создать репозиторий и запушить файлы

На любом компьютере, где есть `git`:

```bash
cd youtube-keep
git init
git add .
git commit -m "YouTube Keep"

# вместо ИМЯ-РЕПО — ваш логин GitHub и название репо, например ivan/youtube-keep
gh repo create ИМЯ-РЕПО --public --source=. --push
```

Если нет `gh`, создайте пустой репозиторий на https://github.com/new и выполните:

```bash
cd youtube-keep
git init
git add .
git commit -m "YouTube Keep"
git remote add origin https://github.com/ВАШ-ЛОГИН/youtube-keep.git
git branch -M main
git push -u origin main
```

### 1.2 Включить GitHub Pages

1. Откройте репозиторий на GitHub  
2. **Settings** → **Pages**  
3. Source: **Deploy from a branch**  
4. Branch: **main** / **/ (root)** → **Save**  
5. Через 1–2 минуты появится ссылка вида:

```text
https://ВАШ-ЛОГИН.github.io/youtube-keep/
```

**Это и есть ваша постоянная ссылка.** Запишите её.

> Репозиторий может быть **public** — данные всё равно лежат в **секретном** Gist, не в репозитории.

### Альтернатива без git (если не хотите GitHub Pages)

1. Откройте https://app.netlify.com/drop  
2. Перетащите папку `youtube-keep` в окно  
3. Получите ссылку вида `https://random-name.netlify.app` — можно переименовать в настройках сайта  

HTTPS и PWA на Netlify тоже работают.

## Шаг 2. «Вход» — создать GitHub Token (один на все устройства)

Токен — это ваш пароль от облачного сейфа. Один и тот же токен вводится на Mac и на телефоне.

1. Залогиньтесь на https://github.com  
2. Откройте: **https://github.com/settings/tokens**  
3. **Generate new token** → **Classic**  
4. Заполните:
   - **Note**: `youtube-keep`
   - **Expiration**: `No expiration` (или 1 год)
   - **Scopes**: отметьте **только** галочку **`gist`**
5. **Generate token**  
6. **Сразу скопируйте токен** (`ghp_…` или `github_pat_…`) — GitHub покажет его **один раз**

Не выкладывайте токен в чат / заметки / скриншоты.

## Шаг 3. Первая настройка на Mac (главное устройство)

1. Откройте ссылку в Chrome или Safari:  
   `https://ВАШ-ЛОГИН.github.io/youtube-keep/`
2. Нажмите **Добавить** и сохраните тестовую YouTube-ссылку (проверка)
3. Внизу сайдбара нажмите **шестерёнку** (Настройки синхронизации)
4. Вставьте:
   - **GitHub Personal Access Token** — токен из шага 2  
   - **Gist ID** — оставьте **пустым** (приложение создаст gist само)
   - Галочка **Автоматическая синхронизация** — включена
5. Нажмите **Отправить в облако**
6. Появится надпись **`Готово. Gist ID: xxxxx`**
7. **Скопируйте Gist ID** (и токен, если ещё где-то не сохранён)

На Mac настройки хранятся в браузере. Данные уже в облаке.

### Установить как приложение (опционально, но удобно)

**Chrome (Mac):** меню ⋮ → **Установить YouTube Keep…**  
**Safari:** меню **Файл** → **Добавить в Dock**  
**Edge:** меню → **Приложения** → **Установить это сайт как приложение**

## Шаг 4. Подключить телефон Android

### 4.1 Открыть ту же ссылку

1. На телефоне откройте **Chrome**
2. Перейдите по **той же ссылке**:  
   `https://ВАШ-ЛОГИН.github.io/youtube-keep/`
3. Войдите в GitHub в Chrome, если попросит (нужен для API синка)

### 4.2 «Войти» — подключить тот же облако

1. На странице приложения: **меню ☰** → **шестерёнка**
2. Вставьте **тот же токен** и **тот же Gist ID** (с Mac)
3. **Галочка автосинка** — включена
4. Нажмите **Загрузить из облака**  
   → ваши ссылки с Mac появятся на телефоне

### 4.3 Установить как приложение

В Chrome: меню ⋮ → **Добавить на главный экран** / **Установить приложение**

Иконка появится на рабочем столе — будет открываться как обычное приложение, без адресной строки.

---

## Шаг 5. Добавить второй компьютер (если нужно)

Повторите шаг 4, но в настольном браузере:

1. Открыть ту же ссылку  
2. Шестерёнка → **тот же токен** + **тот же Gist ID**  
3. **Загрузить из облака**  
4. При желании — установить как приложение

| Действие | Что делать |
|----------|------------|
| Добавить ролик | **Добавить** → вставить ссылку YouTube → **Подтянуть** → указать направление и теги → **Сохранить** |

## Частые проблемы

### На телефоне пусто после «Загрузить»
- Проверьте, что Gist ID **точно** скопирован (без пробелов)
- Токен на телефоне должен быть **тем же**, что на Mac
- Нажмите **Загрузить из облако** ещё раз

### Ошибка 401 / 404 при синке
- **401** — токен неверный или отозван → создайте новый (шаг 2)
- **404** — неверный Gist ID или gist удалён  
  → очистите Gist ID, **Отправить в облако** — создастся новый, затем вставьте новый ID на всех устройствах

### Синк не запускается сам
- В шестерёнке включена галочка **Автоматическая синхронизация**
- Есть и токен, и Gist ID (без Gist ID автосинк не включается)

### Нужно сменить «пароль» (токен)
1. Создайте новый token (шаг 2)  
2. На **каждом** устройстве: шестерёнка → вставить новый токен → **Сохранить настройки**  
3. **Отправить в облако** с одного устройства

### Хочу больше приватности приложения
- GitHub Pages из **private** репозитория доступен на платных тарифах GitHub  
- Или закройте страницу паролем на Netlify / Cloudflare Access  
- Сами **данные** уже защищены: без токена и Gist ID содержимое не получить

### Данные только локально, облако не настроено
Приложение работает офлайн. Настройте шаг 2–3, чтобы включить синк.

## Мини-FAQ

**Нужно ли постоянно логиниться?**  
Нет. Токен сохраняется в браузере устройства после первой настройки. «Вход» = один раз вставить токен + Gist ID.

**Работает ли без интернета?**  
Да, с локальной копией. При появлении сети автосинк отправит изменения.

**Можно ли кинуть ссылку другу?**  
Страницу — да. Ваши данные — нет: без токена и Gist ID его приложение будет пустым. Он заведёт свой token и свой gist.

**iPhone?**  
То же самое: ссылка в Safari → шестерёнка → токен + Gist ID → **Поделиться** → **На экран «Домой»**.

## Итог

1. **Загрузить** `youtube-keep` на GitHub Pages → получить ссылку  
2. **Создать** GitHub token (право `gist`)  
3. **На Mac**: ссылка → шестерёнка → токен → *Отправить* → запомнить Gist ID  
4. **На телефоне**: та же ссылка → шестерёнка → тот же токен + Gist ID → *Загрузить*  
5. **Установить** оба как приложение  

Дальше всё синхронизируется само: добавили на телефоне — появилось на Mac, и наоборот.
